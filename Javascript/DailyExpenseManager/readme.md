# Daily Expense Manager

A simple web-based Expense Manager developed using HTML, CSS, and JavaScript. The application allows users to record, manage, and track their daily expenses through an easy-to-use interface.

## Project Files


DEM.html
DEM.css
DEM.js
README.md

## Features

* Add new expenses
* View expense list
* Calculate total expenses automatically
* Edit existing expenses
* Delete expenses
* Store data using Local Storage
* Simple and responsive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Working

1. Enter the expense name.
2. Enter the expense amount.
3. Click the Add Expense button.
4. The expense is displayed in the expense list.
5. The total expense amount is updated automatically.
6. Users can edit or delete expenses whenever required.

## How to Run

1. Download all project files.
2. Ensure DEM.html, DEM.css, and DEM.js are in the same folder.
3. Open DEM.html in any modern web browser.
4. Start managing your expenses.
